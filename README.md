# 📝 Basic Task Manager

A simple Django-based task manager that allows users to create, track, and manage their daily tasks with priorities and due dates.

---

## 🚀 Features

- ✅ User Authentication (Login, Logout, Register)
- 🗂️ Create, Edit, Delete Tasks
- ⏰ Set Due Dates and Priority Levels
- 🌙 Dark Mode & Responsive Design (Bootstrap)
- 📱 Mobile-friendly UI
- 🔐 Only logged-in users can view their tasks

---

## 🖥️ Tech Stack

- Python & Django
- HTML5, CSS3
- Bootstrap 5
- SQLite (default)
- emojis
